# E1 题库：过期数据 vs 实效数据

生成时间基线：按《刑法》第 12 条（从旧兼从轻）；目标条文 6 条，共 **93** 道题：
* 需要**过期数据**（旧版文本）的题：`questions_old.jsonl`（63 道）
* 需要**实效数据**（现行文本）的题：`questions_new.jsonl`（30 道）

## 情形映射（第 12 条）
* 旧行为·旧审判 / 旧行为·新审判（旧法较轻或相同）→ bank=old；
* 新行为·新审判（行为与审判都在现行法之下）→ bank=new；
* 持续犯/连续犯跨过现行版生效日 → 按设计整体适用新法 → bank=new。

## 判分口径与已知局限
* 判分用原子 nugget：`第X条｜Y年`（条号 + 现行/旧版最高刑年限），与《实验设计书》一致；
* 已过滤『gold 年限 = 现行年限』的题，保证在『只有现行版本』的语料上答错/答对可被区分；
* 情形 1/2（旧法不罪/新法不罪）不适用于本批目标（都是两版均入罪、刑罚有变的条文）；若要覆盖需要另设题面与判分（0 年/无罪无法用现格式表达）；
* 同一条文不同版本年限相同的混淆（如 277 的 1997 版与 2015 版同为 3 年）在『年限』口径下不可再细分，属已知简化。
